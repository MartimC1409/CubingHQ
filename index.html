About

SimTimer — a csTimer-inspired speedcubing practice tool.

Features:

  • Hold spacebar → tap to start (configurable hold)
  • WCA-style 15s inspection with optional voice
  • Per-solve penalty marking (1=OK, 2=+2, 3=DNF)
  • Multiple sessions, all saved locally + optionally cloud
  • Statistics: best Ao5/Ao12/Ao100, single PBs, std dev, success %
  • Click any time to edit, click penalty to cycle
  • Export/Import JSON backup
